Problem & Impact · 20%

Booking an event is a wall of clunky forms.

A graduation, banquet or wedding means choosing from a pile of options — venue, gown, photos, video, menu, diplomas, after-party — across many vendors and spreadsheets. Nobody fills those forms happily.

A conversation is how people actually decide. And these events are rarely decided alone — a whole class or both families weigh in.

Who wins

  • Students, couples, organizers — minutes instead of weeks.
  • Venues & vendors — qualified, complete, budget-fit bookings.
  • Start Global — a booking funnel for every academic event in Romania.

Solution & Innovation · 20%

A conversational planner that actually builds the package.

Claude-style choices

The agent asks one question at a time and shows tappable cards — no forms. Always an "other / type" escape.

Escalating bundles

Per category: Photo / +Booth / +Drone — one or two together, priced live. Pick a tier, move on.

Real venues

Live Google Places within 50 km — photos, ratings, prices — in a rotating carousel.

Group voting

10–20 classmates vote on each option; the winner stays in the shared cart.

Budget-true

"Build it for me within €5,000" fills up to the budget, never over, never dropping essentials.

Tasteful selling

Smart upsells, group/promo discounts, a transparent "unlock a deal" close.

Technology & architecture · 15%

The LLM orchestrates; deterministic code owns the money.

  • Next.js 16 + React 19 + TypeScript + Tailwind, streaming NDJSON chat.
  • Claude Sonnet 4.6 via LLMok, an OpenAI-compatible tool-calling loop.
  • Tools: ask_choice, recommend_tiers, search_venues / discover_places (Google Places), add/remove, propose_package, negotiate_discount…
  • Deterministic engine computes every price/discount — the model never invents numbers.

Robust agent design

  • State digest tells the agent what's captured → no re-asks.
  • Hard budget cap enforced in code.
  • Self-improvement loop: every turn logged → an observer agent finds failures → a 6-scenario regression suite gates each deploy.
